### Deferred

- **RS-T-winsymlink** (CONFIRMED skip). The three tests that make a file symbolic link skip on Windows without Developer Mode or admin rights, so they run only in Linux and macOS CI. Repro: `node --test` on such a machine reports `skipped 3`. With the rights they pass on Windows too: on 2026-11-17, `node --test` run elevated through gsudo (Developer Mode off) reported 81 pass, 0 skipped.
- **RS-A-claudewrite** (fixed in 0.2.1; INFERRED when deferred). The Claude Code skill writes templates with the Write tool after a path check, so a file swapped for a link between the check and the write isn't caught. Listed in SECURITY.md, "Known limits". The Codex copy narrows it: its copy command refuses anything already at the target, and only a dangling link made in the instant between that test and the create-only write would be followed.
- **RS-A-fromlabel** (fixed in 0.2.1; INFERRED when deferred, efficiency). `--check` cuts every `From:` name that is a problem, not only the 50 it prints, so a PLAYBOOK.md with hundreds of thousands of bad names takes about twice as long.
